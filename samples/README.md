## 铁律（§10-6 隐私铁律 / §10-13 文件归置规范）

1. **本目录只允许 `README.md` 进仓库**，任何真实数据（交割单/持仓/账户）一律不入库。
2. **不要往这里放代码** —— 能被 app `import` 的进 `core/` `data/` `ui/`；
   只给人手动敲的脚本进 `scripts/`；验收脚本进 `tests/`。
3. 这里的东西**可以随时删** —— app 运行不依赖本目录任何文件（只是"喂给 app 的输入样例"）。
