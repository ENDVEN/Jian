# samples/ —— 私有样例与参考资料（**不入库**）

这个目录放"**是数据、不是代码**"的东西，例如：

- `实例函数.txt` / `实例函数2.txt` —— 用户自研通达信公式（粘贴进 app 的公式编辑器用）
- `实例交割单2025-0X.xlsx` —— 真实交割单（含资金账户等隐私）

## 铁律（§10-6 隐私铁律 / §10-13 文件归置规范）

1. **本目录内容一律不提交** —— `.gitignore` 里 `samples/*` 已整体忽略
   （只放行本 README），因为这些是隐私数据，开源仓库里绝不能出现。
2. **不要往这里放代码** —— 能被 app `import` 的进 `core/` `data/` `ui/`；
   只给人手动敲命令的脚本进 `scripts/`；验收脚本进 `tests/`。
3. 这里的东西**可以随时删** —— app 的运行不依赖本目录任何文件
   （实例文件只是"喂给 app 的输入样例"）。
