§7-B11 · 后台下载（底部下载条 + 导航角标 + 非模态队列面板）

现状问题：批量预下载是模态弹窗，而且工作线程的 parent 就是弹窗 ⇒ 下载期间整个界面被冻住、窗口不能关，用户只能守着看进度。
本原型 = 把「任务归属」从弹窗搬到主窗口：提交即返回，进度改由全局三处呈现。配色沿用现状白卡 + #1976D2，深色主题仍按既定推迟。

下载条的三态与「一句话说清」

  • 运行中：任务名 + 进度条 + 223/5849 · 正在处理 000622 + 约剩多久（按"真正会联网的只数"算，不再一律报 50 分钟劝退）。
  • 完成：变一条可点回执「✅ 成功 218 · 已最新 5626 · 失败 5 · 查看详情」，几秒后自动收成角标。
  • 失败/中断：原因必须说人话 —— 代理类走 abort_reason_text 唯一出口（「疑似本机代理问题，请检查代理软件是否在运行」），不写死端口。
  • 单行标签只放短状态，长说明进 tooltip；整条水平策略可缩，绝不撑大窗口最小宽度。

为什么还要导航角标

  • 下载条在底部，用户在行情页看 K 线时视线不一定扫到 ⇒ 🗄 数据管理 上一个小橙点，任何页面瞟一眼就知道有活在跑。
  • 点角标 = 切到数据管理页并展开队列面板（一次点击到位）。
  • 空闲时角标与下载条同时隐藏，界面回到今天的样子（不多一块常驻皮）。

队列面板能做什么（都是旧弹窗里已有能力，只是搬出来）

  • 多任务列表：运行中 / 排队中 / 完成 / 部分失败，串行执行（一次只跑一批，与"宁可慢也不封 IP"一致）。
  • 每个任务可单独中断；底部有全部中断。
  • 只重试失败 / 复制失败清单（旧版只能在弹窗里做，弹窗一关就没了）。
  • 面板是非模态的：开着它照样能操作主界面，可以一直挂着当监控窗。

各入口怎么变

  • 批量预下载弹窗：只收集参数；点「▶ 开始下载」= 提交任务，弹窗自动关闭，进度去底部条。
  • 数据管理「更新到最新 / 重新全量下载」：提交即返回，不再锁住整页按钮。
  • M2 / M3「⬆ 更新到最新交易日」：批量任务交队列；页面自己那条进度条改成订阅底部条的投影（进度真源只有一份）。按钮名与文字一律不变。
  • 单只同步（行情页 / 回测滞后补 / 指数补拉）：仍是当页秒级回执，但向队列登记占位，避免全市场下载中途重复抓同一只。
明确不做：并发下载（K=1 串行；并发档另案待拍板）、任务落盘跨进程续传（「跳过已最新」本身就是断点续传）、系统托盘图标、下载中禁止切页（不再需要）。
一条硬约束：退出软件时若队列非空 ⇒ 一次确认「还有 N 个任务在跑，退出会中断」—— 线程运行中被销毁会崩溃，这是 Qt 的既有教训。
