## 1. 十二个设计决定

| # | 决定 |
|---|---|
| ① | **一级页面**（与行情 / 回测同级），不是回测的子页签 |
| ② | **成分唯一来源** = 自选股组（只引用、不复制名单） |
| ③ | 净值图例必须写清"权重 / 再平衡 / 佣金"，否则曲线会被误读 |
| ④ | **基准可选**（指数或**个股**）；换基准只换对照线，不改组合 |
| ⑤ | 持仓表 7 列照截图；"按标的/行业/市场"是同一份数据的三种分组，**不重算** |
| ⑥ | **现金是一等公民**：默认 0%，但表里、环形里、页脚口径里三处都在 |
| ⑦ | **权重三选一**（等权默认 / 市值 / 自定义）+ **"大票吃资金"提示**（不自动改权重） |
| ⑧⑨ | 市场分布 / 行业分布两个环形；行业缺失如实写"未分类"，**不猜** |
| ⑩ | **再平衡记录**只显示软件内事件（时间 / 换手 / 成本），不接券商流水 |
| ⑪ | **页脚口径常驻**（复权 / 佣金 / 基准 / 再平衡 / 权重） |
| ⑫ | 与参数研究**共用池**：B15 池化直接选这个组合（同一 id），不再手写名单 |

## 2. 宽度与自适应（用户 2026-10-26 提的"页面偏长"）

| 窗口宽 | 排布 | 谁让位 | 谁不动 |
|---|---|---|---|
| **≥1440** | 三栏 **300 / 主区 / 330**（整页 max 1560 居中） | — | 全部 |
| **1200–1439** | 三栏 **260 / 主区 / 300** | 组合列表、右栏各收 30–40px | 净值图、持仓表 |
| **1000–1199** | **两栏**：左列表 250 + 主区；**右栏下移成一行三块** | 右栏位置（内容不删） | 图与表 |
| **820–999** | **单列**（列表 → 主区 → 右栏）；左导航收成 **64px 图标** | 导航文字、**成本价列** | 仓位 / 最新价 / 盈亏 |
| **<820** | 单列；组合卡 1 列、右栏 1 列 | 全部让位 | 内容不删 |

**Qt 落地（实现时的硬要求，不是"照抄 CSS"）**

- 用 `QGridLayout` + `resizeEvent` 断点（1200 / 1000 / 820）**重排同一批控件** —— 换位置，不隐藏数据；
- **禁止横向滚动**（§11.5-111）：宁可把右栏下移，也不给横向条；
- 表格**列优先级**：窄窗隐藏「成本价」列（信息进 tooltip 与「组合管理」卡），**绝不压缩字号**；
- 密度可留"紧凑 / 舒适"两档（CSS 变量 ↔ QSS 常量），默认**舒适**；
- 净值图最小高 200、最大 320（与 M3 副图同一套"硬底线 + 封顶"口径）。
