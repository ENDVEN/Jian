M3（广度统计）升级的四张样式稿。现状是"一个方案一条曲线"； 目标是让你这类需求（情绪 ≥80 与 <20 到底和上证什么关系）一眼看得出、并且说得清。
期 1 · 你选的B · 多行小图（柱 + 线）
每项一行、各自 y 轴刻度：柱 = 每日占比 + 5 周均线； 含「行数变多怎么办」的布局统筹规则（焦点行 / 迷你条 / 两列 / 折叠）。
必读E · 选图规则
什么样的条件配什么样的图：命中天数占比 <5% 才能做事件对齐； >30% 只能看占比/IC/回归；以及"n 该按天算还是按家数算"这个最容易错的地方。
期 1A · 多方案叠加
一叠统计项同图：多折线 + 图例 + 悬停各报各的；共享 x 轴接指数副图。 同一段公式的多个判定变量一次扫描拿到（成本最低的一步）。
期 2C · 事件对齐图
把命中日对齐成事件时间（−20…0…+20），画指数平均路径 + ±1σ。 直接回答"命中前涨完了还是命中后才起来" —— 我认为这是最该先做的一张。
期 3D · K 线色带 + 关系量化卡
命中日直接标在指数 K 线上（看位置）；旁边一张卡把关系写成数字： 条件前向收益 / 领先滞后 / Rank IC / 置换检验 p 值，全部带样本量。

建议的落地顺序（每期都能独立交付）

期内容回答什么成本
期 1多统计项（多判定变量同扫）+ A/B 两种表现形式切换 "两个极端同时看，谁先动"低（读盘共享，第 2 项起命中缓存）
期 2
（前置）		E 三道闸：稀疏度闸（>30% 禁用事件图）+ 独立性闸（两种 n 并列）+ 多重检验闸（置换检验 + Bonferroni 提醒） "这个条件到底能不能用事件图看"低（判定是纯函数，界面上只是文案与禁用）
期 2C 事件对齐图（含样本数 / ±1σ / 独立事件口径）+ 对高频条件自动改走"分档 + IC" "命中之后指数怎么走"中（纯计算，可缓存）
期 3D 关系量化卡（IC / 领先滞后 / 置换检验）+ K 线色带 "这关系是真的还是巧合"中（复用参数研究的 IC 口径）
期 4多方案（不同公式/参数/范围）各自缓存 + 统一"统计项"面板 "把几个版本的方案横向比"中高（N 次扫描，缓存兜住）
注意：四张稿里的曲线与数字全部是示意数据（为了讨论表现形式），不是真实统计结果。
请你挑：① 先做哪一期？② 表现形式默认用 A（叠加）还是 B（多行）？ ③ 关系量化卡里你最想要哪几项（我建议：条件前向收益 + 置换检验 p 值 + 领先滞后， Rank IC 可后置）？
