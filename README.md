# Jian · 量化复盘与分析系统

> 桌面端（PyQt6）· 本地优先 · 数据不上云。期货交割单复盘 + A 股行情 / 回测 / 组合，一个程序里两条互不干扰的链路。

---

## 这是什么

| 链路 | 输入 | 你能看到什么 |
|---|---|---|
| **复盘**（只认期货） | 券商/期货公司导出的**交割单 Excel** | 交易流水、逐笔盈亏、资金曲线、月度热力图、深度复盘（K 线 + 买卖点 + 手绘标注） |
| **行情与回测**（只认 A 股，做多） | 公开行情源（可离线看已下载历史） | 日线/分钟 K 线、通达信方言公式回测、全市场筛选、广度统计、参数稳健性研究、**组合层级回测** |

两套数据各存各的：交易流水进 SQLite，行情进本地 Parquet 数据湖；**程序本体与用户数据物理隔离**（`~/.jian_data/`）。

---

## 功能一览

| 页面 | 能力 |
|---|---|
| **概览** | 资金曲线、年度日历热力图、账户摘要 |
| **记录** | 交割单导入、交易流水账、按品种/方向筛选 |
| **复盘** | 单笔交易回放、图表标注（趋势线/水平线/垂直线，按标的与周期保存） |
| **行情** | A 股 / 期货日线与分钟线、自选股与分组、指标叠加（MA/BOLL/MACD） |
| **市场回测** | 单股公式回测 · 全市场筛选 · 广度统计 · 参数研究（含 walk-forward 与池化） |
| **组合** | 组合净值（5 档区间）、持仓表、行业/市场分布、调仓记录（手动改成分 + 月末再平衡） |
| **函数总库** | 公式配方管理（编辑 / 复用 / 送各页） |
| **数据管理** | 批量预下载、分区查看与清理、数据体检（缺口点名） |

## 安装与运行

需要 **Python 3.10+**（开发环境为 3.12，Windows）。

```bash
git clone <repo-url> && cd Jian
pip install -r requirements.txt      # 依赖（全部精确锁定，可直接复现）
python main.py                       # 首次启动会在 ~/.jian_data/ 建数据目录
```

- 不下载行情也能用：导入交割单即可开始复盘。
- 行情需要联网下载一次（数据管理 → 批量预下载）；之后可离线浏览。
- 全部数据都在 `~/.jian_data/`，删掉该目录 = 清空软件数据（程序本身不受影响）。

## 数据来源与口径

- 行情：**AkShare**（A 股日线 **新浪主源 + 东财兜底**；期货新浪主力连续）。免费源，可能缺失或延迟。
- 价格口径：日线默认**前复权**（另存一份不复权）；分钟线只有真实成交价一种口径。
- 指标与回测：纯 Pandas 向量化 + 自研通达信方言 DSL；回测**只做多**、只含佣金、不含滑点。
- 从不用"今天的快照"冒充历史某天的值；缺数据一律标「数据不足」，不填 0。
