## 0. 一句话

**给"公式 + 参数"做一次体检**：把参数网格在**样本内**跑一遍、在**样本外**验一遍，
用 **Rank IC / 邻域稳健 / PBO** 三条口径回答一个问题 ——
**「这套参数化到底稳不稳，哪块参数平台值得用」**，而**不是**"给出这只票的最优参数"。

## 1. 定位与三条红线（产品级，不可妥协）

| 红线 | 说明 | 违反后果 |
|---|---|---|
| **① 样本外只看一次** | 流程固定为「**样本内选、样本外验一次**」。一旦让用户反复用样本外挑参数，样本外就变成样本内 | 研究结果失去全部意义 |
| **② 不承诺"最优参数"** | 界面里**没有**"自动找最优参数"按钮；展示的是**参数平台**与**一致性**，措辞一律"候选/平台/稳健" | 变成过拟合生成器，用户亏钱 |
| **③ 统计前提必须同屏显示** | 交易次数、成本（佣金）、试验次数（网格规模）、PBO 与 IC 必须与排名**同屏**，不许折叠进 tooltip | 用户按"漂亮排名"下注 |

**名词纪律**：本功能内"相关性"一律指 **Rank IC**（排名相关）；`|Δ|`（IS 与 OOS 之差）另有其名：**一致性差**。
（这条是上一轮讨论的核心修正：**|Δ| 只能回答"稳不稳"，不能回答"好不好"**。）

## 2. 口径表（唯一真源，`core/sweep_stats.py` 一处实现）

| 轴 | 指标 | 定义 | 判读 |
|---|---|---|---|
| **① 水平** | `oos_annual` / `oos_win` / `oos_sharpe` / `trades` | 样本外区间的表现 | **只有它**能证明"有本事" |
| **② 一致性** | **Rank IC** = corr(秩(IS 性能), 秩(OOS 性能))（Spearman） | 是**整套网格**的性质（一个数），**不是单个参数的属性** | IC<0.15 ⇒ 该参数化**没有预测力**，别按 IS 冠军选参 |
| ②' | `delta = oos_annual - is_annual`（一致性差） | 单参数属性 | 配合 ① 用；**单独用会选出"平庸但稳定"** |
| **③ 稳健性** | `nb_mean` / `nb_worst` = 该参数在**邻域**（±1 档，3×3 共 9 格）的性能均值 / 最差 | **平台 vs 尖峰**的唯一可靠判据 | 尖峰（自己高、邻居低）≈ 噪声，一律降权 |
| **统计护栏** | **PBO**（回测过拟合概率，CSCV） | 见 §6 伪代码 | **>0.5 ⇒ 这套选参流程等于抛硬币**，界面直接红字警示 |
| 补充 | 成本敏感性：Top-N 候选在 2–3 个佣金档重跑 | 只跑 Top-N，不跑全网格 | 成本一调就崩 ⇒ 不是真本事 |

**排序规则（界面实际执行，写死不许改）**
```
候选 = 满足全部硬门槛的组：
        交易次数 ≥ 门槛（**用户可调**：滑块 5~120，默认停在 30）
        且 IS 年化 > 0  且 OOS 年化 > 0
        ⚠ 门槛**只做筛选、不参与排序键**（别让它污染稳健性口径）；界面须实时显示"当前还剩几组"
排序键 = (邻域稳健 nb_mean 降序, OOS 年化降序, |delta| 升序)
展示   = 「参数平台图」+ 每个候选的 ①②③ 三轴数值 + PBO 红黄绿
禁用   = 任何"按 IS 年化排序"或"取 IS 冠军"的入口
```

## 3. 用户流程（5 步，界面按这个顺序组织）

**左栏顺序 = 用户指定**（2026-09-27）：标的 → 策略 → 参数网格 → 样本区间 → 运行。

| 步 | 用户动作 | 系统动作 | 防呆 |
|---|---|---|---|
| **1 标的** | 选标的（或从「市场行情」页带入） | — | 无本地数据 ⇒ 明确提示"先预下载" |
| **2 策略（函数）** | 从**下拉里选** | **只列「单股回测」里已保存的配方**（不提供自由编辑 ⇒ 省掉本页一半信息量）；用 `probe_missing_parameters()` 列出可扫描参数 | 配方无可扫描参数 ⇒ 该配方置灰 + 说明"本页需要带参数的配方" |
| **3 参数网格** | 填每维范围/步长（每维 ≤15 档） | 实时显示**组合数**与**预计耗时**（§5） | 网格 > 2000 组 ⇒ 拦住并给降档建议 |
| **4 样本区间（预设）** | 选**预设**或自定义 | 预设来自**上证指数切块**（涨/跌/震荡段）**成对**给出样本内/样本外；本机缓存可重算 | 区间起止必须在数据范围内；内外重叠 ⇒ 拦住（重叠 = 泄漏） |
| **5 门槛** | 拖**交易次数门槛**滑块 | 实时显示"还剩几组" + 分布图 + 建议值 | 门槛过高 ⇒ 提示"可能筛掉低频好策略"；引导卡解释"什么是交易次数门槛" |
| **6 运行** | 「▶ 跑样本内」→「▶ 跑样本外」 | 后台逐组回测，存**分段收益序列**（§5 关键设计） | 可中断、增量落盘；**同一网格的样本外只允许跑一次**（红线①） |
| **7 读图 / 落盘** | 读图 → 「存为研究快照」/ 导出 | 落盘到 `~/.jian_data/sweep_results/`（不可变快照 + 索引） | 快照记"配方 + 网格 + 区间预设 + 门槛 + 引擎版本" ⇒ 可复现 |

### ★关键设计决定（这一条决定成败）
> **扫描时把"每组的逐段收益"一起存下来**（例如按 12 段切：`is_segments[12]` / `oos_segments[12]`）。
> 因为 **PBO 与 walk-forward IC 只需要对已有结果做重排，不需要重跑回测**：
> - 重跑方案：PBO 要 `C(12,6)=924` 次组合 × 324 组 = 30 万次回测 ⇒ **不可行**
> - 存分段方案：30 万次**比较** ⇒ **毫秒级**，且滚动 IC 分布、分段稳定性全部免费拿到

## 6. 计算预算（先算账，再谈做）

| 量 | 估算 | 说明 |
|---|---|---|
| 单次回测 | **30–80 ms**（3000 根日线，pandas 向量化） | 与 `core/backtest` 现有实现同量级 |
| 324 组 × 2 段 | **20–50 秒** | 单标的、单线程；放 Worker 里完全可接受 |
| 内存 | 324 × 3000 净值 ≈ **8 MB** | 微不足道（只留 Top-N 全序列，其余留分段收益） |
| PBO / 滚动 IC | **毫秒级** | 只做重排（见 §5 关键设计） |
| ⚠ **池化（N 只 × 324 组）** | 100 只 ⇒ **~1 小时**；5000 只 ⇒ 不可行 | ⇒ **MVP 只做单标的或 ≤20 只的小池** |
| 上限护栏 | 网格组合 ≤ 2000、档数/维 ≤ 15 | 超了在界面就拦住（别让用户点出一个跑一晚上的任务） |

## 7. 统计算法（`core/sweep_stats.py` 伪代码）

```
Rank IC(网格):
    is_rank  = 对 is_annual 求秩(324)
    oos_rank = 对 oos_annual 求秩(324)
    return spearman(is_rank, oos_rank)          # 一个数；<0.15 ⇒ 无预测力

邻域稳健(每组):
    cells = 该组在参数网格中的 3×3 邻居（边界处取存在的）
    return mean(邻居.oos_annual), min(邻居.oos_annual)   # 平台高、邻域不塌 = 好

PBO(CSCV，用已存的"分段收益"):
    S = 12 段（IS+OOS 合起来的整段等分）
    对每个 s ∈ C(S, S/2)：      # 924 个组合
        子集 A = s 段（当 IS） / 子集 B = 其余（当 OOS）
        在 A 上按"我们的排序键"选出冠军 c
        logit = 秩百分位(c 在 B 上的表现)
        记一次 "c 在 B 上是否掉到中位数以下"
    return 掉队次数 / 924        # >0.5 ⇒ 这套选参流程 = 抛硬币（红字警示）

成本敏感性(Top-N):
    对候选表前 N=10 组，用 commission ∈ {万3, 万5, 万10} 重跑 OOS
    return 年化对成本的一阶斜率（越平越好）
```

## 8. 断言清单（机器护栏，进 `smoke_chart` / `smoke_pages_overlay`）

1. **口径唯一**：Rank IC / \|Δ\| / 邻域 / PBO 只在 `core/sweep_stats.py` 实现（源码级：别处不许出现公式）
2. **排序不用 IS**：源码级断言"排序键里不含 `is_annual` 单独成键"，且**不存在**"取 IS 冠军"的调用点
3. **样本外只看一次**：`ParamSweepWorker` 对同一网格的 OOS 只允许跑 **1 次**（第二次要么复用缓存、要么明确要求用户确认"这会污染样本外"）
4. **分段落盘**：结果里必须含 `segments`（否则 PBO 会退回重跑路径 ⇒ 断言拦住）
5. **离网可测**：`sweep_stats` 与 `sweep_plan` 用**合成数据**跑断言（不依赖行情、不依赖 Qt）
6. **PBO 正确性**：用**已知答案的合成序列**验证（构造"IS 冠军必掉队"⇒ PBO→1；构造"完全稳定"⇒ PBO→0）
7. **上限护栏**：网格 > 2000 组 / 档数 > 15 时 `sweep_plan` 返回"拒绝 + 建议"，不是硬跑
8. **可中断**：Worker `cancel()` 后不再发新回测，已跑结果**保留可续**（与下载队列同款语义）
9. **落盘可复现**：快照里必须存"网格 + 日期 + 引擎版本"，读回来能重跑出同一结果
10. **诚实口径**：结论条里的 IC/PBO/交易次数**不可折叠、不可隐藏**（源码级：它们直接进布局，不进 tooltip）
11. **策略来源唯一**（v2）：`param_sweep` 的策略选项**只能来自 `formula_store` 里 M1 保存过的配方**
    （源码级：不存在"现场解析用户手输函数"的入口）
12. **门槛只筛不排**（v2）：`sweep_stats.rank()` 的排序键里**不得出现门槛**；门槛只用来产出"保留/排除"标记
    （断言：改门槛 ⇒ 候选**顺序**不变、只有成员变化）
13. **折叠状态可记忆**（v2）：左栏折叠/展开写偏好（`sweep_ui.panel_collapsed`），重启后还原；
    折叠不丢失任何表单状态（断言：折叠→展开后 5 个字段值不变）
14. **切块可复现**（v2）：上证切块结果落缓存并记"数据末日 + 参数"；同一份数据重跑 ⇒ 段边界不变
    （断言语义：缓存命中不重算、且与现算结果一致）

## 12. 附录 · 设计稿的自检方式（2026-09-28 血泪，务必沿用）

设计稿（HTML 原型）里塞的是**真 JS 图表**，而"调用即抛异常"会让**整段脚本中断 ⇒ 后面所有图都不画**，
肉眼看不出根因。本轮就是这样丢了两轮图。⇒ **改完设计稿必须真跑一遍**，别靠肉眼：

```
node <临时脚本>.js      # 抽 id 建 DOM 桩 → 真跑内联脚本 → 检查每个 class="chart" 是否真画出 <svg>
```
判据：每个图容器 `innerHTML` 必须以 `<svg` 开头，否则即报错并指出是哪一张。

本轮抓到并修掉的两个真 bug（记下来防重犯）：
1. **新写的图函数里用了不存在的 `el()`** —— 该文件上半部分（v1 四张图）里 `el` 只是**参数名**，
   不是一个取节点的函数 ⇒ `ReferenceError`。
2. **v1 的四张图收的是 DOM 元素、不是 id 字符串**（内部直接 `el.innerHTML = …`）⇒ 传 `'p2-scatter'`
   这种字符串会 `TypeError: Cannot create property 'innerHTML' on string`，同样会中断整段脚本。
   ⇒ 新页面统一走 `PS2`（对 id 与元素两种写法都兼容）；`PS` 保持原样，老页面 `a/b/c` 不受影响。
