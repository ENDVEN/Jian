## 0. 一句话目标

把 M3（广度统计）从"**一个方案一条曲线**"升级成：
**多个统计项同屏对比 + 把"与指数的关系"量化出来并如实标注不确定度**。
典型用户诉求（原话）：*"情绪 ≥80 和 <20 这两条极端，到底跟上证指数什么关系？中间那段（20~80）又是什么情况？"*

## 1. 用户拍板的口径（★ 不许擅改）

| # | 决定 | 落地要求 |
|---|---|---|
| 1 | 表现形式**默认 B（多行小图）**；每行 = **柱 + 折线（5 周均）** | 柱**默认「占比」**，必须提供**切「家数」**的选择（顶部下拉，切换不重扫） |
| 2 | 行数多时的布局按**焦点模式**阈值 | 1~3 项＝单列等分；**4~6 项＝焦点行（选中项约 1.6×）+ 迷你条**；7~12 项＝两列网格（宽 ≥1200px）或焦点；>12 项＝折叠非关注项 |
| 3 | E 页三道闸的阈值**默认 `<5%` / `>30%`** | ⚠ **必须可在界面调整，禁止写死**：设置页有项 + 相关页面（C/D/E 就地）有调整入口；**必须有引导**（用户原话：*"这种功能没有引导根本不知道这个阈值到底是啥"*） |

补充硬规则（设计稿里已写死，实现不许破）：
- 底部**指数副图高度固定**（默认 150~190px），绝不随行数被压扁；
- **行区自己滚动**，不让整页跟着滚；
- 所有行 + 副图**共享同一条 x 轴 + 同一条竖向十字线**，读数**统一显示一处**（不在每行各弹一个框）。

## 2. 名词与口径（唯一真源，写进代码注释与界面文案）

| 名词 | 定义 | 易错点 |
|---|---|---|
| **统计项** | 一条"被统计的东西"：公式 + 参数 + **判定变量** + 表现设置（颜色/显隐/柱口径） | 同一段公式可含多个可判定变量（`signal_names`）⇒ **一项 ≠ 一段公式** |
| **命中** | 判定变量在该标的该交易日为真 | 引擎口径：`core.cross_section.scan` 的 `_as_signal` |
| **有效样本** | 当日该标的"数据够、没被硬闸拦掉" | 与"全样本"不同 ⇒ 分母必须明示 |
| **命中家数** | 当日命中标的数 | 与"命中天数"是两件事（见下） |
| **命中天数占比** | 有命中的交易日 / 全部交易日 | **选图规则的判据用它**（不是家数占比） |
| **独立事件** | 命中间隔 ≥ N 个交易日的命中日（N 默认 5，可调） | 连续命中会自我重叠 ⇒ n 虚高，必须给两个 n |
| **置换检验** | 打乱日期顺序重算 M 次（默认 1000），看"随机也能凑出这个差"的概率 | 结果要显示 M 与随机种子（可复现，§10-4） |

## 5. 断言清单（新开工时逐条加进冒烟）

**内核（`smoke_chart.py`）**
1. 多判定变量扫描 == 逐个单独扫描（**逐位一致**）；
2. 缓存键：改判定变量 ⇒ 失效；改柱/显示口径 ⇒ 命中（用"计算调用次数"断言，不靠时间）；
3. `independent_events(gap=5)` 的边界（恰好 5 / 6 天）；
4. `forward_returns` 与手算样例一致（写死 3 组小样本期望值）；
5. `permutation_p` 可复现（固定种子）+ 随机条件下 p 近似均匀（宽松上界即可）；
6. `lead_lag_corr` 对"人工构造领先 5 期"的序列峰值落在 −5；
7. `gate_decision` 的阈值闭开区间（=5%、=30% 各算一档）。

**页面（`smoke_pages_overlay.py`）**
8. 统计项面板：加/删/显隐/换色后行数与图例一致；
9. 柱口径切换（占比↔家数）**不触发重扫**（断言 worker 未启动）；
10. 行数 4 与 6 ⇒ 焦点模式生效；3 ⇒ 等分（判据用控件属性，不用像素）；
11. C/D 页禁用态：34% 条件 ⇒ 显示禁用 + 含"原因/替代/动作"三要素；（负向对照）2% 条件 ⇒ 可用；
12. 阈值偏好脏值（0/负/交叉）⇒ 夹边界或拒绝，且界面显示的阈值 == 实际生效值（**不许两处不一致**）；
13. 引导条：首次出现、可关闭、再次进入不再弹（**且手动入口永远在**）。

### 9.5 跨期统一的交互原则（免得每期一套新习惯）

1. **一次扫描 → 多视图**：能靠切视图解决的，绝不重新扫；
2. **可调的阈值/尺寸**一律：就地入口 + **与设置页同一份偏好** + 改完立即生效（纯函数 / 纯渲染）；
3. **禁用态三要素**：原因（带数字）· 替代方案 · 动作；
4. **诚实边界固定位**：口径脚注（L0）、样本量与显著性（关系卡）永远同屏；
5. **空态 / 缺帧 / 样本不足**：如实说，不画假图、不拿零线凑；
6. 新增**任何**"记住上次"的键 ⇒ 同一次改动里加进冒烟抹平列表（§11.5-132）。
