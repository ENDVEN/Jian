## 0. 一句话

把散在三处的用户函数收进**一个资产库**（`formula_store` 扩展），给一个**总库管理页（A）** +
各功能页的**浮窗快速取用（B）**：总库管增删查改 / 编写 / 语法体检 / 引用；功能页只管"选一个函数载进来跑"。

## 1. 三条红线（产品级，实现时直接写成断言）

| # | 红线 | 违反后果 |
|---|---|---|
| ① | **总库只管资产，不管运行**：总库/浮窗里没有任何"运行回测 / 跑扫描 / 画图"入口 | 出现第二套运行面 = 口径分裂 |
| ② | **绝不静默改变已存方案的函数**：M1 策略 / M2·M3 方案载入时**内联快照优先**（现行为零变化）；资产有更新版 ⇒ 一次性提示 `[用最新版] / [保留旧版]`，默认**保留** | 回测可复现性被破坏：重跑悄悄换了函数，档案/签名全错 |
| ③ | **迁移绝不猜拆、绝不丢数据**：老 M1 档无 `segments` ⇒ 整体一段；坏条目跳过自己；写回一律原子写；迁移幂等（跑 N 次结果一致） | 用户策略库被改坏 = 事故 |

**名词纪律**：**函数资产** = `formula_store` 里的一条配方（segments + params_text）；
**引用** = M1 策略 / M2·M3 方案里存的 `asset_id`；**内联快照** = 方案里继续保留的公式文本（兼容与兜底）；
**来源 origin** = 资产的出生地（`market` / `backtest` / `scan` / `hub`，扩展既有 `source` 字段，不新增字段名）。

## 2. 数据模型（提案① · 定案）

**关键决定：不新建 store —— `formula_store.FormulaStore` 就是资产库本体**（形状现成：
`{id, name, segments[{text,target}], params_text, source, created_at, updated_at, used_at}`，
且已有单例纪律 `get_formula_store()`、原子写、按名 upsert、touch/rename/delete）。

| 引用方 | 保存时 | 载入时 | 兼容 |
|---|---|---|---|
| 行情页 | 本来就直用资产（存配方 = upsert 资产） | 载入资产 + `touch(used_at)`（现行为） | 零改动 |
| M1 策略 | `payload()` 追加 `asset_id`（当前函数段按内容/名命中资产，无则新建，origin=backtest）；**`segments`/`function` 字段原样保留** = 内联快照 | `apply_payload()` 照旧用快照还原；**新增**：`asset_id` 命中且资产内容 ≠ 快照 ⇒ 状态行一次性提示"总库有更新版"，给 `用最新版` 按钮（点了才覆盖 segments/params） | 老档无 `asset_id` ⇒ 全部路径回落现行为 |
| M2/M3 方案 | `config` 追加 `asset_id`（formula 内容命中/新建，origin=scan）；`formula`/`params` 原样保留 | 照旧用内联 `formula`；新增同款"总库有更新版"提示 | 同上 |

- **引用计数 = 动态计算**（不落盘）：扫 `strategy_store` 与 `scan_strategy_store` 里 `asset_id` 命中数；
  行情页的 `used_at` 单列为"最近使用"，**不算引用**。
- **删除保护（§10-10 分级）**：无引用 ⇒ 红色二次确认；有引用 ⇒ 键入「删除」+ 引用清单列出；
  删除后引用方**回落内联快照**（方案照常可用，`asset_id` 置空）——绝不损坏方案。
- **总库编辑资产** ⇒ 引用方不静默变（红线②）；总库回执点名"N 个方案引用此函数，它们仍用旧版"。

## 3. 迁移设计（H1 · `data/hub_migration.py` 唯一实现）

- 触发：`main.py` 启动后调 `ensure_hub_migration()` 一次（读三库毫秒级）；总库页/浮窗打开时兜底再调（幂等）。
- 规则（逐条）：
  1. M1 策略：`asset_id` 已有 ⇒ 跳过。`segments` 存在 ⇒ 按段导入；**只有 `function` ⇒ 整体一段（绝不按分号猜拆）**。
  2. M2/M3 方案：`asset_id` 已有 ⇒ 跳过；`config.formula` ⇒ 一段（target=`main`，扫描无窗格概念，总库可改）。
  3. 命名：资产名 = 来源名；**同名但内容不同** ⇒ 追加后缀 ` ·M1` / ` ·扫描`（诚实标注，绝不静默覆盖用户手存配方）。
  4. `params`/`params_text` 原样并入资产 `params_text`；坏条目（无公式文本）跳过并记日志。
  5. 写回：三库各 `save()` 一次（原子写）；迁移标记 `hub_migration: 1` 写进资产库 payload。
- **冒烟必须用临时库**（§11.5-32/90：绝不写真实 `~/.jian_data`）。

## 6. 护栏（实现时全进冒烟）

1. 资产库唯一真源 = `formula_store`；**禁止**第三处再存公式副本格式（M1/M2M3 的内联字段只降级为快照，不许再长新用途）。
2. 红线②机器化：M1 `apply_payload` / M2M3 方案载入**只读快照字段**（源码级断言：载入路径不许直接读资产内容）。
3. 迁移幂等：跑两次 = 跑一次（条数/内容/asset_id 逐位一致）；无 segments 老档 ⇒ 整体一段（断言"绝不出现按 `;` 拆出的残段"）。
4. 删除保护：有引用必须键入确认；删除后引用方 `asset_id` 置空且快照完好（方案可载入）。
5. 总库编辑器报错**非阻断**（`FormulaCompileError` 只进结果条，绝不弹模态打断）。
6. 浮窗 = 唯一非模态浮层范式：不持 QThread、关闭不销毁数据、`hub_ui` 位置记忆（照 §7-B11 四条口径）。
7. 配置区不可侵犯：M1 条件/风控/门控/成交控件、M2/M3 阈值/范围控件在 H3 里**零 diff**（diff 审查项）。
8. 新 json 键：无新文件；`hub_ui` 偏好键加入 `smoke_pages_overlay` 防污染自检名单（第 9 个）。
9. 迁移/总库/浮烟全部用临时库；真实 `~/.jian_data` 零写入（现有防污染自检延续）。
10. 字体/控件/宽度纪律照旧（§10-9/15）：新编辑器用 `mono_font_css()`，按钮走 `styles.py` 家族。
