> **位置**：用户定位 = **与「市场行情」「市场回测」同级的一级页面**（左栏第 7 项，`📊 组合`）。
> **一句话**：把"自选股组"升级成**可回测的组合** —— 组合 = 一组标的 + 权重 + 基准 + 规则；
> 页面按用户截图（富途牛牛「组合」）的**信息架构**做；**配置好的组合直接复用行情页已写好的自选股组**。
> **优先级**：用户 2026-10-25 定为**后续最高优先级待办**（`JIAN_RULES.md` 断点首条）。
> **与 B15 的关系**：B15「完整版」的"≤20 只小池"**不再手写名单** ⇒ **直接选一个组合**，做**组合层级回测**。

## 三、数据模型（最小可用）

```
Portfolio:
  id            组合唯一 id
  name          名称（用户可改）
  source_group  来源：行情页「自选股」组名（★核心对接点）
  members       [{symbol, name, weight}]   # 权重（合计 = 100% - cash）
  cash          现金比例（0~100%）
  base          基准（默认 沪深300；可选 上证/中证500/自选代码）
  started_at    建仓日（用于"自估成本"）
  rules         {rebalance: 'buy_hold' | 'monthly' | 'quarterly', fee: 跟随全局「回测佣金」}
```

**关键约束**：
- **成分的来源只有一处**：`行情页 → 自选股 → 组`（用户已有的东西）。**不新建第二份名单**（§11.5-112）。
- **权重口径**：`等权`（默认）/ `市值权重` / `自定义`；保存时**规一化成百分比**并在界面上显示合计。
- **成本口径**：与 1.81 的**全局「回测佣金」同源**（不另造一个费率）；滑点/印花税仍无模型 ⇒ 文案写"只含佣金"。
- **复权**：前复权日线（与全站一致）；组合净值 = 各成分日收益按权重加权（**再平衡规则**决定权重漂移）。

## 五、六个口径问题 —— **已拍板（用户 2026-10-26）**

| # | 问题 | **用户决定** | 设计含义（写进 P0–P4 的硬要求） |
|---|---|---|---|
| 1 | 权重 | **等权默认**；但**必须给"市值 / 自定义"** | 用户原话："会存在个别股票价值巨大，资金买完就没多少钱买其他的" ⇒ 三选一 + **"大票吃资金"提示**（按金额取整时提示，**不自动改权重**） |
| 2 | 再平衡 | **买入持有 + 按月** | 两种规则都要在记录里写明；按季暂不做（留扩展位） |
| 3 | 基准 | **默认沪深300**；~~可选其它指数，甚至个股~~ → **♻ 2026-10-28 改口径：下拉只列指数 / 行业指数**（用户实测"出现很多代码严重影响使用体验"） | 基准只换对照线，**不改组合**；图例写清"基准：XXX"；**名称唯一真源 = `data/akshare_feed.INDEX_PRESETS`**（认不出的本地指数**不列**、个股不再作为基准）；**基准缺的交易日不画线、也不当 0 收益** |
| 4 | 现金 | **支持，默认 0%** | 用户原话："有些时候真的会存在用户持有现金跑赢所有组合的情况" ⇒ 现金是**一等公民**（持仓表常驻一行 + 环形里常有一块） |
| 5 | 成本 | **接全局「回测佣金」**（1.81），不新增费率 | 组合回测与单股回测**同一口径**；页脚常驻"佣金 万X（可改）" |
| 6 | 调仓记录 | **只显示软件内再平衡**，不接券商流水 | 记录 = 时间 / 换手 / 成本，可点开看明细 |

> ⚠ 现金与权重的关系：`成员权重合计 + 现金 = 100%`；改现金时**按比例缩放成员**（并在界面上显示缩放前后，别静默）。

## 六、风险与红线（先说清）

- **不许造"实时"**：只有日线收盘，图例上要写清"日线（收盘）"，不假装分时。
- **不许把"组合"做成第二份自选股**：成分唯一来源 = 行情页自选股组（§11.5-112 同族）。
- **不许出现"推荐/最优组合"字样**（红线②同族：软件摆事实，不替你选）。
- **组合回测 = 组合层面的统计**：不得暗示"按这个组合买就能赚"；文案沿用现有诚实边界（幸存者偏差 / 相关≠因果 / 只含佣金）。
- **性能**：≤20 只 × 日线 10 年 ⇒ 毫秒级；若要全市场加权，必须先在界面限制并给预估时间。

### A2. 基准（★1.90 口径改版，2026-10-28 用户实测）

- **只列指数 / 行业指数**：显示名取 `data/akshare_feed.INDEX_PRESETS`（30 项，含大盘/红利/科创/行业/北交所），
  先"已下载"再"未下载（点了会提示去数据管理补）"；**认不出名字的本地指数文件不列**（旧版直接显示 `899050` 这类裸代码）。
- **个股不再作为基准**：历史存档里的个股基准仍**原样显示**为「当前 · 不在指数预设内」（不静默换成沪深300）。
- **缺日不填 0**：`index_daily` 与组合交易日不同时，缺的那段**留 NaN（断线）**，卡头写明"基准自 X 起才有数据"，
  超额收益只在**共同区间**上计算（旧版填 0 收益 ⇒ 画出一条假平线 + 超额失真）。

### B. **P0-0 前置改造（必须先做）**：主导航从"下标路由"改成"身份路由"

**现状（实测）**：`main_window` 里是 `_PAGE_INDEX = {"market": 3, "backtest": 4, "hub": 5, "data": 6, "settings": 7}`
+ `btn.clicked.connect(lambda: content_area.setCurrentIndex(N))` + 角标点击也写死 `setCurrentIndex(6)`。

**风险**：插入「组合」必然让 `数据管理/设置` 的 index 漂移 ⇒ **静默错页**（本项目 §11.5-130 在 M1–M3 子页签上已经翻过这个车）。

**做法**：
1. `_PAGES = {"market": self.page_market, ...}`（**存 widget 不存下标**）；
2. `switch_to(key)` 改 `self.content_area.setCurrentWidget(self._PAGES[key])`；
3. 导航按钮一律 `clicked.connect(lambda: self.switch_to('portfolio'))`；
4. 角标那处 `setCurrentIndex(6)` 改 `switch_to("data")`；
5. 断言：**逐 key 遍历 `_PAGES`，切过去后 `contentArea.currentWidget() is 该页`**（插页后仍全过）。

### C. P0 数据层：`data/portfolio_store.py`（新）

- 落盘 `~/.jian_data/portfolios/index.json`（组合元数据）+ 每条一个 `pf-<id>.json`（或单文件，二选一，**P0 用单文件**更简单）；
- 字段：`id / name / source_group / members[{symbol, weight}] / cash / base / rebalance / created_at / schema_version`；
- **不存成分快照**：只存 `source_group` + 只读引用 ⇒ 组改名/移组自动跟随（这是"唯一来源"的落地）；
- 写入用 **临时文件 + `os.replace`**（断电不半写）；`schema_version` 预留迁移；

### G. 动工时需要你点头的 4 个细则（都有默认值）
